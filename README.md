# -README

Ein Übungs-Repository, um den Ablauf von Pull Requests auf GitHub kennenzulernen.

## Inhalt

- `README.md` – diese Datei mit einer kurzen Beschreibung des Projekts.

## Mitmachen

1. Einen neuen Branch erstellen: `git checkout -b mein-branch`
2. Änderungen vornehmen und committen: `git commit -am "Beschreibung der Änderung"`
3. Den Branch pushen: `git push -u origin mein-branch`
4. Auf GitHub einen Pull Request öffnen.
